# Agenda CRE
Projeto independente do repositório pai. Não alterar arquivos do projeto de reset de senhas.
Stack: React/TypeScript, Express, SQLite nativo do Node 24, sessões no banco.
Preservar isolamento por regional e autorização no servidor. Nunca versionar banco, senhas ou .env.
Antes de concluir mudanças funcionais: npm run build e npm test.
